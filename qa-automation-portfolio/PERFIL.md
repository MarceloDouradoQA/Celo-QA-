**Descrição para o LinkedIn**

Portfólio prático de automação de testes sobre uma loja de demonstração. Os cenários cobrem checkout, indisponibilidade de catálogo, falha de rede, regras de estoque e consistência de dados. Inclui Playwright, Cypress, Selenium com Java e JUnit, Postman/Newman, pytest, SQL e k6, com pipeline de CI no GitHub Actions.
